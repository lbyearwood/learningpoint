The purpose of the CPU

The Central Processing Unit, or CPU, is the part of the computer that processes instructions. It carries out the instructions in programs and controls the movement of data around the computer system.

The CPU repeatedly fetches instructions from memory, decodes them so it knows what to do, and executes them. This repeated process is called the fetch-execute cycle.

Activity 1: Explain the CPU

Write a short answer explaining the purpose of the CPU.

The CPU processes program instructions and controls the movement of data in the computer. It repeatedly fetches, decodes and executes instructions.

The fetch-execute cycle

The fetch-execute cycle is the repeated process the CPU uses to run program instructions.

StageWhat happens
FetchThe CPU gets the next instruction from memory.
DecodeThe CPU works out what the instruction means and what must be done.
ExecuteThe CPU carries out the instruction, such as a calculation, comparison or data movement.

At GCSE level, focus on the main action at each stage. You do not need to describe detailed data transfers between registers at every stage.

Von Neumann architecture

Von Neumann architecture is a computer architecture where program instructions and data are stored in the same memory. The CPU fetches instructions from memory and processes them using registers and CPU components.

Registers are small, fast storage locations inside the CPU. Some registers store data, while others store memory addresses. This distinction is important.

Data vs address

Data is the value or instruction being used. For example, the number 42, the letter A, or a program instruction can be data.

An address is a location in memory where data or an instruction can be found. An address is like a label that tells the computer where to look.

For this topic, remember: the MAR stores an address, the Program Counter stores an address, the MDR stores data or an instruction, and the Accumulator stores data from calculations.

Exam-style questions

Question 1

Definition

State what CPU stands for.

Central Processing Unit.

Question 2

CPU purpose

2 marks

Describe the purpose of the CPU.

The CPU processes program instructions and controls the movement of data around the computer system.

Question 3

CPU components

3 marks

Explain the role of three CPU components.

The ALU performs arithmetic and logic operations. The CU controls and coordinates CPU activity. Cache stores frequently used data and instructions close to the CPU for faster access.

Question 4

Fetch-execute cycle

4 marks

Describe the fetch-execute cycle.

The CPU fetches the next instruction from memory. It decodes the instruction to work out what it means. It then executes the instruction by carrying out the required action. This cycle repeats while the program is running.

Question 5

Von Neumann architecture and registers

6 marks

Explain Von Neumann architecture and the purpose of the MAR, MDR, Program Counter and Accumulator.

Von Neumann architecture stores program instructions and data in the same memory. The MAR stores the address of the memory location being used. The MDR stores data or an instruction being transferred to or from memory. The Program Counter stores the address of the next instruction. The Accumulator stores intermediate results from calculations.
