GCSE Computer Science OCR J277

Characters

Learn how computers represent letters, digits, punctuation and symbols using binary character codes.

Learning checklist

  • I can explain how characters are represented using binary codes.
  • I can define the term character set.
  • I can explain the difference between ASCII and Unicode.
  • I can explain how the number of bits per character affects the number of possible characters.
  • I can explain why character sets are logically ordered.
  • I can recognise that ASCII characters in the exam use 8-bit binary.

How computers store characters

Computers store all data using binary. Characters such as letters, digits, punctuation marks and symbols are also stored using binary codes.

Each character is assigned a unique binary code. When the computer stores text, it stores the binary code for each character in the text. A character such as A is stored as a binary code, but you do not need to memorise the exact code for the exam.

Example: storing the word CAT

C to 01000011
A to 01000001
T to 01010100

This is an 8-bit ASCII example. You need to understand the idea, not memorise full character code tables.

Activity 1: Storing a word

Character sets

A character set is a collection of characters and the binary codes used to represent them. It tells the computer which binary code represents which character.

Different character sets can represent different numbers and ranges of characters. The table below uses illustrative example codes only. You do not need to memorise character set codes.

Character set mapping

A character set defines which binary code represents each character.

Example character codes

Character Example binary code Meaning
A 01000001 The uppercase letter A
B 01000010 The uppercase letter B
7 00110111 The digit 7

Activity 2: Define it

Bits per character

The number of bits used for each character limits how many different characters can be represented. More bits means more possible binary combinations.

The number of possible characters can be calculated using 2^number of bits.

Bits decide the number of possible characters

Possible characters = 2 ^ number of bits
1 bit2 possible characters
2 bits4 possible characters
3 bits8 possible characters
4 bits16 possible characters
8 bits256 possible characters
more bits to more combinations to more characters

Activity 3: Calculate combinations

If a character set uses 8 bits per character, how many different characters can it represent?

8 bits can represent 2^8 combinations, which is 256 possible characters.

ASCII

ASCII is a character set. It is commonly used to represent English letters, digits, punctuation and control characters.

In the OCR exam, binary representation of ASCII will use 8 bits. ASCII is limited compared with Unicode because it cannot represent as many characters from different languages and symbol systems.

You do not need to memorise ASCII codes. You do need to understand that each character has a binary code.

Activity 4: ASCII limits

Unicode

Unicode is a larger character set. It can represent a much wider range of characters, symbols and languages.

Unicode is useful for modern systems because software and websites may need to support many languages and symbols. If more bits are used per character, Unicode can require more storage than smaller character sets.

ASCII compared with Unicode

ASCII

  • Smaller character set
  • English letters, digits and common symbols
  • OCR exam representation uses 8 bits
  • Limited compared with Unicode

Unicode

  • Much larger character set
  • Many languages and symbols
  • Better for global systems
  • Wider range of characters

ASCII is useful for a smaller range of text. Unicode is designed for modern systems that need a much wider range of characters.

Activity 5: ASCII and Unicode

Think through the differences between ASCII and Unicode.

ASCII is more limited and is mainly suitable for English letters, digits and common symbols. Unicode can represent many more characters, including characters from different languages and symbol systems.

Logical ordering

Character sets are arranged in a logical order. For example, the code for B is one more than the code for A.

This means computers can compare and sort characters. It also helps explain why letters can be processed in order.

Logical sequence

A code value
+1
B next value
+1
C next value

Character sets are logically ordered, which helps computers compare and sort characters.

ASCII and Unicode

Global website

3 marks

OCR J277 understanding

3 marks

The student does not need to memorise every code. They need to understand that characters are represented by binary codes in a character set, that ASCII uses 8-bit binary in the exam, and that character codes are logically ordered.
