1D lists or arrays workbook

Learn how a 1D list or array stores several related values under one name.

Learning checklist

  • I can define a 1D list or array.
  • I can explain why lists or arrays are useful.
  • I can identify the elements stored in a list or array.
  • I can use an index to read a value from a list or array.
  • I can explain that a 1D list or array is a single row of values.
  • I can choose when a list or array is more suitable than separate variables.
  • I can trace simple code that reads values from a list or array.

What is a 1D list or array?

A 1D list or array is a data structure that stores several values under one name.

The values in a list or array are called elements. A 1D list or array stores these elements in one line or sequence.

One name, many values

List name Elements stored
scores [12, 9, 15, 7]
names ["Ava", "Sam", "Noor"]

The list name lets the program refer to the whole collection of related values.

Activity 1: Define it

A 1D list or array is a data structure that stores multiple related values in one sequence under one name.

Why use a list or array?

A list or array is useful when a program needs to store many related values. It avoids creating lots of separate variables.

Separate variables compared with a list

Separate variables 1D list or array
score1 = 8
score2 = 10
score3 = 6		 scores = [8, 10, 6]
Harder to process if there are many values. Easier to loop through, search, count or update.

Activity 2: Explain the benefit

The scores are related values, so storing them in one list is clearer and easier to process, especially if the program needs to loop through them.

Elements in a 1D list or array

Each value stored in a list or array is an element. The number of elements is the length or size of the list or array.

Counting elements

colours = ["red", "blue", "green", "yellow"]

This list has 4 elements: red, blue, green and yellow.

Activity 3: Count and identify

Look at this list:

temperatures = [18.5, 19.0, 17.5]

There are 3 elements: 18.5, 19.0 and 17.5.

Indexing in a 1D list or array

An index is the position number used to read a specific element from a list or array.

In these examples, the first element is at index 0. This means scores[0] reads the first value, scores[1] reads the second value, and so on.

Index positions

List Index Value read
scores = [4, 7, 9] scores[0] 4
scores = [4, 7, 9] scores[1] 7
scores = [4, 7, 9] scores[2] 9

Activity 4: Read by index

Look at this list:

names = ["Ava", "Sam", "Noor"]

names[1] reads "Sam", because index 1 is the second element.

Reading from a list or array

A program can read values from a list or array and use them in calculations or output.

Example trace

scores = [4, 7, 9]
total = scores[0] + scores[1] + scores[2]
print(total)

The program reads the values from the list and adds them to total. The output is 20.

Activity 5: Trace the values

What total would be calculated by this code?

marks = [5, 6, 8]
total = marks[0] + marks[1] + marks[2]

The total is 19 because 5 + 6 + 8 = 19.

Choosing when to use a list or array

Use a list or array when values belong together and the same kind of processing may happen to each value.

Good uses

Data Why a list or array helps
Scores for a class The program can find totals, averages or highest scores.
Names in a team The program can search, display or count names.
Temperatures recorded each day The program can compare values across the week.

Activity 6: Choose a structure

A list or array is suitable because the 30 scores are related values. Storing them together makes them easier to count, total, search or process with a loop.
