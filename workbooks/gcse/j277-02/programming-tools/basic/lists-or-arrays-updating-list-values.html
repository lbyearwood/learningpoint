OCR J277 · 2.2 Programming fundamentals

Updating list values workbook

Learn how programs replace an existing value in a 1D list or array using its index.

Learning checklist

  • I can explain what it means to update a list or array value.
  • I can use an index to choose which element is updated.
  • I can trace the value of a list before and after an update.
  • I can explain that updating replaces the old value.
  • I can identify errors caused by using the wrong index.
  • I can write simple code that updates a list or array element.

What does updating mean?

Updating a list or array value means replacing one existing element with a new value.

The list keeps the same name and the same position. Only the value stored at that position changes.

Before and after

Code List after the line runs
scores = [4, 7, 9] [4, 7, 9]
scores[1] = 10 [4, 10, 9]

scores[1] is the second element, so 7 is replaced with 10.

Activity 1: Define it

Updating a list or array value means replacing an existing element with a new value, usually by using its index.

Using an index to update

An index tells the program which element to change. In these examples, the first element is at index 0.

Index positions

List Update Result
names = ["Ava", "Sam", "Noor"] names[0] = "Mia" ["Mia", "Sam", "Noor"]
names = ["Ava", "Sam", "Noor"] names[2] = "Kai" ["Ava", "Sam", "Kai"]

Activity 2: Update by index

Look at this list:

colours = ["red", "blue", "green"]
colours[0] = "yellow"

The list becomes ["yellow", "blue", "green"].

Tracing several updates

A list can be updated more than once. Trace each line in order because later updates use the current list, not the original one.

Example trace

scores = [3, 5, 8]
scores[0] = 4
scores[2] = scores[1] + scores[2]
After line List value
scores = [3, 5, 8] [3, 5, 8]
scores[0] = 4 [4, 5, 8]
scores[2] = scores[1] + scores[2] [4, 5, 13]

Activity 3: Trace updates

What is the final value of numbers?

numbers = [2, 4, 6]
numbers[1] = 10
numbers[2] = numbers[0] + numbers[1]

The final list is [2, 10, 12].

Replacing, not inserting

Updating an element replaces the value at that index. It does not add a new element to the list.

Replacement example

items = ["pen", "bag", "book"]
items[1] = "ruler"

The list becomes ["pen", "ruler", "book"]. It still has 3 elements.

Activity 4: Replacement or extra value?

There are still 3 elements. The value at index 1 has been replaced; no new element has been added.

Using the wrong index

An update only works if the index exists. A list with 3 elements has indexes 0, 1 and 2 in these examples.

Index error example

scores = [4, 7, 9]
scores[3] = 10

This would cause a problem because there is no index 3. The last element is at index 2.

Activity 5: Spot the problem

The list has three elements, so the valid indexes are 0, 1 and 2. Index 3 does not exist.

scores = [6, 8, 10]

The final value is [6, 12, 10].

Explain

3 marks

It updates the element at index 2, which is the third element in these examples, and replaces it with "Mia".
