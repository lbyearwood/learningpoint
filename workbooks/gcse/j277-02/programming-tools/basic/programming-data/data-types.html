Data types

Learn how Python stores different kinds of values and why the type affects what a program can do with them.

Learning checklist

  • I can define data type.
  • I can identify strings, integers, floats and Booleans.
  • I can choose a suitable data type for a scenario.
  • I can explain why data types affect operations in Python.
  • I can explain why some numbers are stored as strings.

What a data type is

A data type tells the program what kind of value is being stored. The data type affects what operations can be carried out on that value.

Different data types are suitable for different kinds of data. A name is handled differently from a score, a decimal measurement or a True/False decision.

Worked example: checking types

name = "Asha"
age = 15
height = 1.68
is_member = True

print(type(name))
print(type(age))
print(type(height))
print(type(is_member))

Python can report the type of each value. The values above are a string, integer, float and Boolean.

Strings, integers, floats and Booleans

A string stores text. In Python, string values are written inside quotation marks.

name = "Asha"
postcode = "RM12 4AB"

Some numbers are stored as strings when they are not used for calculations. Phone numbers and postcodes are good examples because leading zeros and letters matter.

An integer is a whole number with no decimal point. It is suitable for counts, scores and whole-number quantities.

age = 15
score = 42

A real number is a number with a decimal point. In Python these are called floats. They are useful for measurements, money approximations, averages and decimal values.

price = 2.99
temperature = 37.5

A Boolean stores either True or False. Booleans are used in conditions and decisions, so they connect directly to selection.

is_logged_in = True
has_passed = False

String, integer, float, Boolean, string, integer.

Choosing suitable data types

Choose a data type by thinking about how the value will be used. A value that looks like a number may still be better as a string if it will not be used in a calculation.

Activity 2: Choose the best type

Username: string. Number of lives: integer. Product price: float. Password correct: Boolean. Average speed: float. Exam mark: usually integer.

Activity 3: Phone numbers

A phone number is not normally used for maths. It may contain a leading zero, spaces or symbols, so storing it as a string preserves the exact text.

Why data types matter

Python handles operations differently depending on the data type. Two integers can be added. Two strings are joined together, which is called concatenation.

Worked example: addition

score = 10
bonus = 5
print(score + bonus)

This outputs 15 because both values are integers.

Worked example: joining strings

score = "10"
bonus = "5"
print(score + bonus)

This outputs 105 because both values are strings. The values are joined together instead of added.

Type casting is used to convert values between data types. This workbook only introduces why conversion might be needed; the separate Type casting workbook teaches conversion in detail.

Activity 4: Predict the output

age = "15"
print(age + age)

The output is 1515. age stores a string, so + joins the two strings.

Common mistakes

  • Thinking all numbers should be integers.
  • Storing decimal values as integers.
  • Storing numbers as strings and expecting maths to work.
  • Confusing "True" as a string with True as a Boolean.
  • Using a float when a whole number is more appropriate.
  • Choosing a data type without thinking about how the value will be used.
  • Trying to add text and numbers together without conversion.

Exam-style questions

Question 1

Define

1 mark

A data type tells the program what kind of value is being stored.

Question 2

Identify

4 marks

"Blue" is a string, 12 is an integer, 4.5 is a float and False is a Boolean.

Question 3

Justify

2 marks

An integer is suitable because age is usually stored as a whole number of years.

Question 4

Compare

2 marks

An integer is a whole number with no decimal point. A float is a number that can include a decimal point.

Question 5

Explain

2 marks

A postcode can contain letters, numbers and spaces. It is not used for calculations, so string is suitable.

Question 6

Predict

3 marks
first = "7"
second = "3"
total = 7 + 3
print(first + second)
print(total)

The output is 73 then 10. The first line joins two strings, while the second line adds two integers.
