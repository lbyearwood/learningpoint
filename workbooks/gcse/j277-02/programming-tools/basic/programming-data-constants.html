OCR J277 · 2.2 Programming fundamentals

Constants workbook

Learn how programs use constants to store important values that should not change while the program runs.

Learning checklist

  • I can define the term constant.
  • I can explain the difference between a variable and a constant.
  • I can identify when a value should be stored as a constant.
  • I can explain why constants make code easier to maintain.
  • I can choose clear names for constants.
  • I can trace simple code that uses constants in calculations.

What is a constant?

A constant is a named value that should not change while a program is running.

Constants are useful for values that have a fixed meaning, such as a tax rate, maximum score, number of lives, password length limit or conversion rate used throughout a program.

Activity 1: Define it

A constant is a named value in a program that should not change while the program is running.

Constants and variables

Variables and constants both give names to values. The key difference is whether the value is expected to change.

Activity 2: Spot the difference

A variable's value can change while the program runs, but a constant's value should stay the same.

Why use constants?

Constants make code easier to read because the name explains what the value means. They also make code easier to update because the value is written once and reused.

If the value needs to change later, the programmer can change the constant in one place instead of finding every copy of the same number in the program.

Example

Less clear Clearer with a constant
total = price * 1.2 VAT_RATE = 1.2
total = price * VAT_RATE
The value 1.2 has no meaning unless you already know what it represents. VAT_RATE explains the purpose of the value.

Activity 3: Explain the benefit

VAT_RATE explains what the value means. If the VAT rate changes, the programmer can update the constant once rather than changing lots of separate values.

Naming constants

Constants should have clear names that describe the value. Many programmers write constant names in uppercase with underscores, such as MAX_ATTEMPTS.

Clear constant names

Constant name Value Purpose
MAX_ATTEMPTS 3 Maximum number of login attempts.
PASS_MARK 50 Score needed to pass.
FREE_DELIVERY_LIMIT 25 Minimum order value for free delivery.

Activity 4: Choose a name

A clear answer could be MAX_STUDENTS, MAX_CLASS_SIZE or CLASS_LIMIT.

Tracing code with constants

Constants can be used in calculations. The constant value is read whenever it is needed, but it should not be changed by the program.

Example trace

POINTS_PER_WIN = 3
wins = 4
points = wins * POINTS_PER_WIN

The value of POINTS_PER_WIN is 3, so points becomes 12.

Activity 5: Calculate using a constant

What is the final value of total?

ITEM_PRICE = 5
quantity = 6
total = quantity * ITEM_PRICE

The final value of total is 30 because 6 * 5 = 30.

Exam-style questions

Question 1

Definition

2 marks

A constant is a named value in a program that should not change while the program is running.

Question 2

Usefulness

3 marks

MAX_ATTEMPTS makes the code easier to read because it explains what the value means. The value should not change while the program runs. If the allowed number of attempts changes later, the programmer can update it in one place.

Question 3

Trace code

2 marks

What is output by this code?

PASS_MARK = 50
score = 42
score = score + 10
print(score)

The output is 52. PASS_MARK is not changed; score is updated from 42 to 52.
