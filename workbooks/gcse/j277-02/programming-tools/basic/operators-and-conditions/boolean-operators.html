Boolean operators

Learn how AND, OR and NOT are used to combine or reverse conditions.

Learning checklist

  • I can describe Boolean values.
  • I can explain and, or and not.
  • I can use Boolean operators in Python conditions.
  • I can complete simple truth tables.
  • I can choose the correct Boolean operator for a scenario.

AND and OR

A Boolean operator combines or reverses Boolean values. Python uses lowercase and, or and not. and means both conditions must be true. or means at least one condition must be true.

age = 15
has_permission = True

if age >= 13 and has_permission:
    print("Allowed")

temperature = 30
is_sunny = False

if temperature > 25 or is_sunny:
    print("Go outside")

Activity 1: Choose AND or OR

Use and, because both conditions must be true.

Activity 2: Predict output

Go outside is printed because temperature > 25 is true.

NOT and truth tables

not reverses a Boolean result. not True becomes False, and not False becomes True.

logged_in = False

if not logged_in:
    print("Please log in")

Activity 3: Complete a truth table

False, because both conditions are not true.

Activity 4: Write AND

age >= 13 and has_permission

Activity 5: Write OR

score > 90 or bonus_unlocked

Activity 6: Explain NOT

not reverses a Boolean value, so True becomes False and False becomes True.

Common mistakes

  • Thinking OR means only one condition can be true.
  • Thinking AND means either condition is enough.
  • Forgetting that NOT reverses a result.
  • Writing AND or OR in capital letters in Python examples.
  • Using Boolean operators without complete comparisons.
  • Overcomplicating simple conditions.
