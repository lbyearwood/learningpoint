Comparison operators

Learn how Python compares values to produce True or False results.

Learning checklist

  • I can identify comparison operators.
  • I can explain that comparisons return True or False.
  • I can distinguish assignment from comparison.
  • I can use comparisons in Python if statements.
  • I can predict True/False outcomes.

Comparing values

A comparison operator compares two values. The result is a Boolean value: True or False.

age = 15
print(age >= 13)

score = 50
print(score == 50)

password = "open"
print(password != "closed")

Activity 1: Identify the operator

>= means greater than or equal to. It checks whether age is at least 13.

Activity 2: Predict True or False

False, True, True.

Assignment is not comparison

In Python, = stores a value in a variable. == checks whether two values are equal.

Activity 3: Fix the comparison

if password == "open":

Comparisons in selection

Comparison operators are often used as conditions inside if statements.

mark = 72
if mark >= 50:
    print("Pass")

Activity 4: Choose the operator

age >= 18

Activity 5: Password check

password == "open"

Common mistakes

  • Using = instead of ==.
  • Reading >= as greater than only.
  • Confusing < and >.
  • Forgetting comparisons return True or False.
  • Using the wrong comparison for boundary values.
  • Comparing strings and numbers incorrectly.
