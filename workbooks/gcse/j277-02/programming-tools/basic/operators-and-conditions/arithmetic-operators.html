Arithmetic operators

Learn how Python performs calculations using arithmetic operators.

Learning checklist

  • I can identify Python arithmetic operators.
  • I can use +, -, *, /, //, % and **.
  • I can explain integer division and modulo.
  • I can apply operator precedence.
  • I can predict the output of arithmetic expressions.

Arithmetic operators in Python

An arithmetic operator tells Python to perform a calculation. OCR exam reference language may show DIV and MOD, but Python uses // for integer division and % for modulo.

Worked examples

total = 10 + 5
print(total)

difference = 20 - 8
print(difference)

product = 6 * 4
print(product)

answer = 10 / 2
print(answer)

Activity 1: Calculate outputs

The outputs are 12, 7, 15 and 4.0. Python division with / produces a decimal-style result.

Activity 2: Identify operators

*, the multiplication operator.

Integer division, modulo and powers

// gives the whole-number quotient. % gives the remainder. ** raises a number to a power.

whole = 17 // 5
remainder = 17 % 5
print(whole)
print(remainder)

power = 2 ** 3
print(power)

Activity 3: Predict // and %

22 // 4 is 5 and 22 % 4 is 2.

Activity 4: Complete missing operators

Use * for multiplication and % for remainder.

Precedence and brackets

Python follows operator precedence. Multiplication, division, integer division and modulo happen before addition and subtraction unless brackets change the order.

result = 3 + 4 * 2
print(result)

result = (3 + 4) * 2
print(result)

Activity 5: Total price

item_price = 4
quantity = 3
total = item_price * quantity
print(total)

Activity 6: Explain brackets

The brackets make 3 + 4 happen first, so the expression becomes 7 * 2, which is 14.

Common mistakes

  • Using x instead of * for multiplication.
  • Confusing / with //.
  • Misunderstanding modulo as division.
  • Forgetting operator precedence.
  • Not using brackets when a calculation needs grouping.
  • Expecting division to always produce a whole number.
