Multi-term conditions

Learn how to build Python conditions using multiple comparisons and Boolean operators.

Learning checklist

  • I can define a multi-term condition.
  • I can combine more than one comparison.
  • I can use and, or and not.
  • I can write range, invalid input and login checks.
  • I can use brackets to make complex conditions clearer.

Building a multi-term condition

A multi-term condition combines more than one comparison. Each comparison must be complete in Python.

Activity 1: Identify the parts

The comparisons are age >= 13 and age <= 18. The Boolean operator is and.

Range checks and invalid input

Use and when a value must be inside a range. Use or when a value is invalid if it is below one limit or above another.

age = 16
if age >= 13 and age <= 18:
    print("Teenager")

score = 85
if score < 0 or score > 100:
    print("Invalid score")

Activity 2: Predict the result

False, because age >= 13 is false.

Activity 3: Write a range check

score >= 0 and score <= 100

Activity 4: Write an invalid input check

score < 0 or score > 100

Login checks, NOT and brackets

Multi-term conditions are useful in if statements, but they can become hard to read. Brackets make groups clearer.

username = "admin"
password = "letmein"

if username == "admin" and password == "letmein":
    print("Access granted")

temperature = 20
raining = False

if temperature > 18 and not raining:
    print("Good weather")

Activity 5: Login check

if username == "admin" and password == "letmein":
    print("Access granted")

Activity 6: Fix the condition

age >= 13 and age <= 18

Common mistakes

  • Writing age >= 13 and <= 18 instead of age >= 13 and age <= 18.
  • Using OR when AND is needed for a range.
  • Using AND when OR is needed for invalid input.
  • Forgetting brackets in complex conditions.
  • Making conditions too long and hard to read.
  • Not testing boundary values.
