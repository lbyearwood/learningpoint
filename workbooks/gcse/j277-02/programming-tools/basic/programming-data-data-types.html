OCR J277 · 2.2 Programming fundamentals

Data types workbook

Learn how data types tell a program what kind of value is being stored and what can be done with it.

Learning checklist

  • I can define the term data type.
  • I can identify strings, integers, real numbers and Boolean values.
  • I can choose a suitable data type for a value.
  • I can explain why programs need to know the data type.
  • I can describe problems caused by using the wrong data type.
  • I can trace simple code that uses different data types.

What is a data type?

A data type describes the kind of value stored in a variable or constant.

The data type matters because it affects what operations can be carried out. For example, numbers can be used in calculations, but text is usually treated as characters.

Same-looking value, different meaning

Value Data type How the program treats it
7 Integer A whole number that can be used in calculations.
"7" String Text made from characters.

Activity 1: Define it

A data type describes the kind of value stored, such as text, a whole number, a decimal number or True/False.

Common data types

OCR J277 programming questions often use these common data types.

Core examples

Data type Meaning Examples
String Text made from characters. "Sam", "A12", "hello"
Integer A whole number. 0, 17, -4
Real or float A number with a decimal part. 3.5, 0.25, -2.8
Boolean One of two logical values. True, False

Activity 2: Identify the types

"Maya" is a string, 42 is an integer, 6.5 is a real/float, and False is Boolean.

Choosing suitable data types

A programmer should choose the data type that matches how the value will be used.

Choosing examples

Data to store Suitable data type Reason
A student's name String Names are text.
Number of lives left Integer Lives are counted as whole numbers.
Temperature such as 18.5 Real or float The value may include a decimal part.
Whether a user is logged in Boolean There are two possible states: True or False.

Activity 3: Choose the type

A real or float is suitable because the price can include a decimal part.

Why data types matter

The wrong data type can make code behave incorrectly or cause an error. A common example is storing a number as a string.

Number or text?

Expression Likely result Reason
7 + 3 10 Both values are numbers.
"7" + "3" "73" in many languages Both values are strings, so they are joined as text.
"7" + 3 May cause an error The program is trying to mix text and a number.

Activity 4: Explain the problem

"20" is a string, so the program may treat it as text rather than a number. It may need to be converted before arithmetic can be carried out.

Exam-style questions

Question 1

Definition

2 marks

A data type describes the kind of value being stored, such as a string, integer, real/float or Boolean.

Question 2

Choosing types

4 marks

Username: string. Age: integer. Height in metres: real/float. Whether payment has been made: Boolean.

Question 3

Reasoning

3 marks

The data type tells the program what kind of value is stored and what operations are suitable. For example, numbers can be used in arithmetic, strings can be joined as text, and Boolean values can be used in conditions.
