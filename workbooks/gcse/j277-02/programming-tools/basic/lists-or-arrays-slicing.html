Slicing workbook

Learn how Python can copy part of a list using slice notation.

Learning checklist

  • I can explain what slicing does.
  • I can use Python slice notation with a start and stop value.
  • I can explain that the stop position is not included.
  • I can slice from the start of a list.
  • I can slice to the end of a list.
  • I can trace the output of simple list slices.

What is slicing?

Slicing means taking a copy of part of a list. In Python, a slice uses a colon inside square brackets.

A slice does not change the original list unless the program assigns a new value back into the list. In this workbook, the slices make new shorter lists.

Slice idea

colours = ["red", "blue", "green", "yellow"]
chosen = colours[1:3]

chosen becomes ["blue", "green"]. The original colours list is still unchanged.

Activity 1: Define it

Slicing means copying part of a list to create a smaller list.

Start and stop values

The general Python pattern is list_name[start:stop].

The slice starts at the start index and stops before the stop index. The stop index is not included.

Start included, stop excluded

Code Result Why
numbers = [10, 20, 30, 40, 50] [10, 20, 30, 40, 50] The full list
numbers[1:4] [20, 30, 40] Starts at index 1 and stops before index 4
numbers[0:2] [10, 20] Starts at index 0 and stops before index 2

Activity 2: Trace a slice

What is stored in part?

letters = ["a", "b", "c", "d", "e"]
part = letters[2:5]

part is ["c", "d", "e"]. The slice starts at index 2 and stops before index 5.

Slicing from the start

If the start value is left blank, Python starts from the beginning of the list.

From the start

scores = [4, 7, 9, 12]
first_two = scores[:2]

first_two becomes [4, 7]. Python starts at index 0 and stops before index 2.

Activity 3: First values

What is stored in first_three?

names = ["Ava", "Sam", "Noor", "Mia"]
first_three = names[:3]

first_three is ["Ava", "Sam", "Noor"].

Slicing to the end

If the stop value is left blank, Python continues to the end of the list.

To the end

scores = [4, 7, 9, 12]
last_three = scores[1:]

last_three becomes [7, 9, 12]. Python starts at index 1 and keeps going to the end.

Activity 4: End values

What is stored in ending?

items = ["pen", "bag", "book", "ruler"]
ending = items[2:]

ending is ["book", "ruler"].

Slicing does not edit the original list

A slice creates a new list containing the selected elements. The original list stays the same.

Original list unchanged

items = ["pen", "bag", "book", "ruler"]
small_list = items[1:3]
Variable Value
small_list ["bee", "cat"]
items ["pen", "bag", "book", "ruler"]

Activity 5: Original or copy?

No. The slice creates a new list. The original items list still contains all four values.

Exam-style questions

Question 1

Trace a slice

2 marks

What is stored in result?

values = [2, 4, 6, 8, 10]
result = values[1:4]

result is [4, 6, 8].

Question 2

Explain notation

3 marks

It creates a new list from the start of names up to, but not including, index 2.

Question 3

Stop value

2 marks

No. The stop value is not included. The slice includes index 1 and index 2, then stops before index 3.
