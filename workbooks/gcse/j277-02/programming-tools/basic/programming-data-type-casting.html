OCR J277 · 2.2 Programming fundamentals

Type casting workbook

Learn how programs convert values from one data type to another so they can be used correctly.

Learning checklist

  • I can define the term type casting.
  • I can explain why input often needs to be type cast.
  • I can convert strings to integers or real numbers for calculations.
  • I can convert numbers to strings for output.
  • I can identify errors caused by unsuitable conversions.
  • I can trace simple code that uses type casting.

What is type casting?

Type casting means converting a value from one data type to another.

Programs use type casting when a value is stored as one type but needs to be used as another type. A common example is user input: input is often received as a string, even if the user typed a number.

Activity 1: Define it

Type casting is converting a value from one data type to another, such as converting a string to an integer.

Why input often needs casting

When a program asks the user to type something, the input may be stored as a string. If the program needs to do arithmetic, the string must be converted to a number first.

Activity 2: Explain the cast

The input is stored as a string. It must be converted to an integer before the program can add 1 as a number.

Casting for calculations

Different casts are used for different kinds of numbers. Use an integer cast for whole numbers and a real/float cast for decimal values.

Choosing the cast

Input value Needed type Suitable cast
"8" Integer int("8")
"4.99" Real or float float("4.99")
16 String str(16)

Activity 3: Choose the cast

A real/float cast is most suitable, such as float("6.5"), because the value includes a decimal part.

Casting for output

Sometimes a number must be converted to a string before it can be joined with other text for output.

Output example

score = 12
message = "Score: " + str(score)
print(message)

str(score) converts the number to text so it can be joined to "Score: ".

Activity 4: Explain the output

score is a number. It is converted to a string so it can be joined with the text "Score: ".

Invalid casts

Not every value can be converted to every type. A program may crash or produce an error if the cast does not make sense.

Safe and unsafe examples

Cast Likely outcome Reason
int("15") Works The string contains a whole number.
float("15.5") Works The string contains a decimal number.
int("hello") Error The string does not contain a valid number.

Activity 5: Spot the error

"cat" is text that does not represent a whole number, so it cannot be converted to an integer.

Exam-style questions

Question 1

Definition

2 marks

Type casting is converting a value from one data type to another so it can be used in the required way.

Question 2

Input

3 marks

The input may be stored as a string. To add 1 as a number, the program needs to convert "15" to an integer first, for example using int("15").

Question 3

Trace code

2 marks

What is output by this code?

numberText = "6"
number = int(numberText)
print(number + 4)

The output is 10. The string "6" is converted to the integer 6, then 4 is added.
