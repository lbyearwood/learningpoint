Condition-controlled loops

Learn how Python while loops repeat code until a condition changes.

Learning checklist

  • I can define a condition-controlled loop.
  • I can identify a Python while loop condition.
  • I can explain how the loop body repeats.
  • I can update a variable inside a loop.
  • I can recognise sentinel values.
  • I can avoid infinite loops.

What a condition-controlled loop is

A condition-controlled loop repeats while a condition is true. The number of repeats is not always known before the loop starts.

Python uses a while loop for condition-controlled iteration. The condition is checked before each repeat.

Basic while loop

count = 1
while count <= 5:
    print(count)
    count = count + 1

The update line is important because it changes count, so the condition can eventually become false.

Activity 1: Identify the condition

count = 1
while count <= 5:
    print(count)
    count = count + 1

The condition is count <= 5.

Tracing while loops

When tracing a while loop, check the condition before each repeat, then update the variable inside the loop.

Activity 2: Predict output

count = 1
while count <= 3:
    print(count)
    count = count + 1

The output is 1, 2, 3.

Activity 3: Missing update

count = 1
while count <= 5:
    print(count)
    ...

count = count + 1

Indefinite repetition and sentinel values

A while loop is useful when the program does not know how many attempts or values there will be.

User input loop

password = ""
while password != "open":
    password = input("Enter password: ")
print("Access granted")

The loop continues until the password is "open".

Sentinel-controlled loop

total = 0
number = int(input("Enter a number, or -1 to stop: "))
while number != -1:
    total = total + number
    number = int(input("Enter a number, or -1 to stop: "))
print(total)

The sentinel value is -1. It tells the program to stop entering numbers.

Activity 4: When does it stop?

It stops when password is equal to "open".

Activity 5: Write a password loop

password = ""
while password != "open":
    password = input("Enter password: ")
print("Access granted")

Infinite loops

An infinite loop keeps repeating because the condition never becomes false. This can freeze a program or make it keep producing output.

Infinite loop warning

while True:
    print("This will keep going")

This can be dangerous unless there is a clear break condition. The condition True does not change by itself.

Activity 6: Identify the problem

count = 1
while count <= 5:
    print(count)

count is never updated, so count <= 5 stays true forever.

Common mistakes

  • Forgetting to update the variable inside the loop.
  • Creating an infinite loop.
  • Using = instead of == when explaining equality checks.
  • Forgetting the colon at the end of the while line.
  • Forgetting indentation.
  • Using a while loop when a for loop would be simpler.
  • Not thinking about what makes the condition become false.
