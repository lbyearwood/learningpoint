Count-controlled loops

Learn how Python for loops repeat code a known number of times.

Learning checklist

  • I can define iteration.
  • I can explain what a count-controlled loop is.
  • I can use Python for loops and range().
  • I can trace start, stop and step values.
  • I can spot off-by-one errors.
  • I can choose when a count-controlled loop is suitable.

What iteration means

Iteration means repetition. A loop repeats a block of code.

A count-controlled loop is used when the number of repeats is known before the loop starts. In Python, this is usually written as a for loop.

Basic repeat

for i in range(5):
    print("Hello")

This prints Hello five times. The loop variable is i.

Activity 1: How many repeats?

for i in range(5):
    print("Hello")

It runs 5 times.

Using range()

range() creates the sequence of values used by the loop. A common GCSE mistake is thinking range(5) means 1 to 5. It actually produces 0 to 4.

Counting from 0 to 4

for i in range(5):
    print(i)

The output is 0, 1, 2, 3, 4.

Counting from 1 to 5

for i in range(1, 6):
    print(i)

The stop value is 6 because Python stops before the stop value.

Activity 2: Predict output

for i in range(1, 4):
    print(i)

The output is 1, 2, 3.

Activity 3: Complete range values

for i in range(...):
    print(i)

Use range(1, 11).

Step values and list loops

A third value in range() is the step. It controls how much the loop variable changes each time.

Using a step

for i in range(2, 11, 2):
    print(i)

The output is 2, 4, 6, 8, 10.

Looping through a list

names = ["Asha", "Ben", "Cara"]
for name in names:
    print(name)

The loop variable name takes each list value in turn.

Activity 4: Print even numbers

for i in range(2, 21, 2):
    print(i)

Activity 5: Loop through a list

for name in names:
    print(name)

Off-by-one errors

An off-by-one error happens when a loop runs one too many or one too few times. This often happens because the stop value in range() is not included.

Activity 6: Explain range(1, 6)

Python includes the start value but stops before the stop value, so a stop value of 6 is needed for 5 to be printed.

Common mistakes

  • Thinking range(5) prints 1 to 5.
  • Forgetting the colon at the end of the for line.
  • Forgetting to indent the loop body.
  • Using the wrong stop value.
  • Changing the loop variable unnecessarily inside the loop.
  • Using a for loop when the number of repeats is not known.

    print(i)

    print(i)

Off-by-one

3 marks

A common error is using range(1, 5) to try to print 1 to 5. It only prints 1 to 4 because the stop value is excluded.
