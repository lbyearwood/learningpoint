What does searching a list mean?

Searching a list means checking the elements in the list to see whether a particular value is stored.

The value being searched for is often called the target. A search may return whether the target was found, or the index where it was found.

Search idea

List Target Outcome
names = ["Ava", "Sam", "Noor"] "Sam" Found at index 1
names = ["Ava", "Sam", "Noor"] "Mia" Not found

Activity 1: Define it

Searching a list means checking its elements to find whether a target value is stored in the list.

Linear search

A simple way to search a list is a linear search. This checks each element in order until the target is found or the list ends.

Writing lots of separate if statements for scores[0], scores[1], scores[2] and so on is poor practice because it only works for a fixed-size list and creates repeated code. A loop is the correct way to search a list in Python.

Checking in order with Python

scores = [4, 7, 9]
target = 7
found = False

for score in scores:
    if score == target:
        found = True

The target 7 is found when scores[1] is checked.

Activity 2: Trace a search

Look at this list:

colours = ["red", "blue", "green"]
target = "green"

The target "green" is at index 2.

Searching with an index loop

When a list could contain many values, writing a separate if statement for every index is not practical and should be avoided. A loop can repeat the same check for each index.

A Python for index in range(...) loop is useful when the program needs to know the position where the target is found.

Index loop search

scores = [4, 7, 9]
target = 7
position = -1

for index in range(0, len(scores)):
    if scores[index] == target:
        position = index

The loop checks index 0, then index 1, then index 2. The target is found at index 1, so position becomes 1.

Activity 3: Trace an index loop

What final value should position have?

letters = ["a", "b", "c", "d"]
target = "c"
position = -1

for index in range(0, len(letters)):
    if letters[index] == target:
        position = index

The final value is 2 because "c" is stored at index 2.

Searching with a value loop

A Python for value in list loop works like a for-each loop. It is useful when the program only needs to know whether the target exists. It checks each value directly, without using an index.

Value loop search

names = ["Ava", "Sam", "Noor"]
target = "Noor"
found = False

for name in names:
    if name == target:
        found = True

The loop checks each name in the list. When "Noor" is checked, found becomes True.

Activity 4: Trace a value loop

What final value should found have?

items = ["pen", "bag", "book"]
target = "ruler"
found = False

for item in items:
    if item == target:
        found = True

The final value is False because "ruler" is not stored in the list.

Using a found flag

A program can use a Boolean variable, often called a flag, to remember whether the target has been found. In Python, a found flag is normally updated inside a loop.

Found flag example

names = ["Ava", "Sam", "Noor"]
target = "Noor"
found = False

for name in names:
    if name == target:
        found = True

found starts as False. It becomes True when "Noor" is checked.

Activity 5: Found or not found?

What is the final value of found?

items = ["pen", "bag", "book"]
target = "ruler"
found = False

for item in items:
    if item == target:
        found = True

The final value is False because "ruler" is not in the list.

Finding the index

Sometimes it is not enough to know that a value exists. The program may also need to know the index where it was found.

Position example

numbers = [12, 18, 25]
target = 18
position = -1

for index in range(0, len(numbers)):
    if numbers[index] == target:
        position = index

position becomes 1 because 18 is at index 1. A value such as -1 can mean not found.

Activity 6: Find the position

What final value should position have?

letters = ["a", "b", "c"]
target = "a"

The position should be 0 because "a" is the first element.

Not found

If the target is not in the list, the search should clearly show that it was not found.

This can be done with found = False, position = -1, or a message such as "Not found".

Activity 7: Explain not found

-1 can be used to mean not found. If the target is found, the program replaces -1 with the real index.
