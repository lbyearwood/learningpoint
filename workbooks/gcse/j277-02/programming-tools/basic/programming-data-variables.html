Variables workbook

Learn how programs use variables to store values that can change while a program is running.

Learning checklist

  • I can define the term variable.
  • I can explain why programs use variables.
  • I can identify a variable name and its value in code.
  • I can explain that a variable value can change while a program runs.
  • I can choose clear variable names.
  • I can trace simple code that updates variables.

What is a variable?

A variable is a named storage location in a program. It stores a value so the program can use it later.

The value stored in a variable can change while the program is running. The variable name stays the same, but the value it holds can be replaced.

Activity 1: Define it

A variable is a named storage location that stores a value used by a program. The value can change while the program runs.

Assigning values

Assignment means putting a value into a variable. In pseudocode and many programming languages, the value on the right is stored in the variable on the left.

Example assignments

Code Meaning
score = 0 Store the value 0 in the variable called score.
name = "Amira" Store the text Amira in the variable called name.
lives = 3 Store the value 3 in the variable called lives.

Activity 2: Explain an assignment

It stores the value 1 in the variable called attempts.

Changing a variable

A variable can be updated. When a new value is assigned to the same variable, the old value is replaced.

Activity 3: Trace the value

What is the final value of points?

points = 4
points = points + 6
points = points - 3

The final value is 7. The value starts at 4, becomes 10, then becomes 7.

Variable names

Clear variable names make programs easier to read. A good variable name should describe the data being stored.

For example, totalScore is clearer than x if the variable stores a player's total score.

Clearer names

Weak name Clearer name Why it is clearer
n studentName Shows that the value is a student's name.
t totalCost Shows that the value is a total cost.
a age Shows that the value is an age.

Activity 4: Choose a name

A clear answer could be livesLeft, remainingLives or numberOfLives.

Variables and data types

Variables can store different kinds of data, such as numbers, text or Boolean values. The kind of value stored is called the data type.

Examples

Variable Example value Kind of data
score 12 Integer
username "Max" String
gameOver False Boolean

Activity 5: Identify the value

Look at this code:

username = "Sam"
score = 8
score = score + 2

username is "Sam". score is 10.

total = 5
total = total + 3
print(total)
