ELSE IF statements

Learn how ELSE IF checks several possible outcomes in order.

Learning checklist

  • I can explain why ELSE IF is used.
  • I can trace conditions in order.
  • I can identify the first true condition.
  • I can explain why condition order matters.
  • I can write grade, band or category decisions.

More than two outcomes

ELSE IF is used when there are more than two possible outcomes. The program checks each condition in order.

As soon as one condition is true, that branch runs and the remaining branches are skipped.

Activity 1: Why ELSE IF?

ELSE IF is used when the program has more than two possible outcomes to choose from.

Grade boundaries

Worked example

mark = 68

if mark >= 80 then
    print("Grade 8")
elseif mark >= 60 then
    print("Grade 6")
else
    print("Keep improving")
endif

The output is Grade 6. The first condition is false, then the second condition is true.

Activity 2: Predict output

mark = 84
if mark >= 80 then
    print("Grade 8")
elseif mark >= 60 then
    print("Grade 6")
else
    print("Keep improving")
endif

Grade 8 is printed. The remaining branches are skipped.

Activity 3: First condition

mark >= 80 is checked first.

Why order matters

The order of ELSE IF conditions matters when ranges overlap. Put the most specific or highest boundary first.

Activity 4: Explain order

Because a high score also satisfies score >= 40. If the lower boundary is first, the program will run the wrong branch and skip the higher grade branch.

Activity 5: Write ELSE IF

if age < 12 then
    print("Child")
elseif age < 18 then
    print("Teen")
else
    print("Adult")
endif

Common mistakes

  • Putting conditions in the wrong order.
  • Forgetting that the first true branch runs.
  • Expecting later branches to run after one branch has already matched.
  • Leaving out a final ELSE when a fallback is needed.
