ELSE statements

Learn how ELSE gives a program a false branch as well as a true branch.

Learning checklist

  • I can explain why ELSE is used.
  • I can identify the true and false branches.
  • I can explain that exactly one branch runs.
  • I can read IF ELSE code.
  • I can write simple IF ELSE decisions.

Why ELSE is used

An IF statement handles what happens when a condition is true. An ELSE statement handles what happens when the same condition is false.

In an IF ELSE structure, exactly one branch runs: either the IF branch or the ELSE branch.

Activity 1: Explain ELSE

ELSE is useful because it tells the program what to do when the IF condition is false.

Two-path decisions

ELSE is best when there are two possible outcomes.

Worked example

temperature = 16

if temperature >= 20 then
    print("Warm")
else
    print("Cold")
endif

The output is Cold because the condition is false.

Activity 2: Predict true

score = 72
if score >= 50 then
    print("Pass")
else
    print("Try again")
endif

Pass is printed.

Activity 3: Predict false

password = "cat"
if password == "secure" then
    print("Accepted")
else
    print("Rejected")
endif

Rejected is printed.

IF ELSE structure

Activity 4: Complete the ELSE branch

if password == "letmein" then
    print("Accepted")
else
    ...
endif

print("Rejected")

Activity 5: Write IF ELSE

if password == "open" then
    print("Accepted")
else
    print("Rejected")
endif

Common mistakes

  • Thinking both branches run. Only one branch runs.
  • Forgetting that ELSE is the false path.
  • Writing another condition after ELSE. ELSE does not need a condition.
  • Forgetting endif at the end.
