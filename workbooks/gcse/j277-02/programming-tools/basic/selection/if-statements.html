IF statements

Learn how a program uses an IF statement to make a one-way decision.

Learning checklist

  • I can define selection.
  • I can identify the condition in an IF statement.
  • I can explain that the IF block only runs when the condition is true.
  • I can use comparison operators in simple conditions.
  • I can read and write simple IF statements.

What selection means

Selection is when a program chooses whether to run some code based on a condition. An IF statement is the simplest selection tool.

The condition is a test that is either true or false. If it is true, the indented action in the IF block runs. If it is false, the IF block is skipped.

Activity 1: Define selection

Selection is when a program chooses which code to run based on whether a condition is true or false.

Conditions and comparison operators

An IF statement often uses a comparison operator such as >, >=, <, <=, == or !=.

Worked example

score = 62

if score >= 50 then
    print("Pass")
endif

Because 62 >= 50 is true, the output is Pass.

Activity 2: Identify the condition

The condition is score >= 50.

IF statement structure

OCR-style pseudocode uses if, then and endif. The action is placed inside the IF block.

Activity 3: Predict the output

age = 15

if age >= 16 then
    print("Can apply")
endif

Nothing is printed because 15 >= 16 is false.

Activity 4: Write an IF statement

if age >= 18 then
    print("Adult")
endif

Common mistakes

  • Forgetting to write a condition after if.
  • Thinking the IF block always runs. It only runs when the condition is true.
  • Using assignment when a comparison is needed.
  • Forgetting that ELSE, ELSE IF and nested IF statements are later selection tools.
