Match case

Learn how match case, also called switch case, can handle fixed menu choices cleanly.

Learning checklist

  • I can describe match case or switch case selection.
  • I can explain when it is useful.
  • I can identify the case that runs.
  • I can explain the purpose of default.
  • I can write a simple menu selection.

What match case does

Some programming languages call this match case. OCR's reference language uses switch/case. Both mean checking one value against several fixed cases.

It is useful for menus, commands and fixed options such as "A", "D" or "Q".

Activity 1: When is it useful?

It is useful for a menu where the user chooses a fixed option such as A, D or Q.

Reading switch/case code

Worked example

choice = "A"

switch choice:
    case "A":
        print("Add item")
    case "D":
        print("Delete item")
    default:
        print("Invalid option")
endswitch

The output is Add item because choice matches case "A".

Activity 2: Predict output

choice = "D"
switch choice:
    case "A":
        print("Add item")
    case "D":
        print("Delete item")
    default:
        print("Invalid option")
endswitch

Delete item is printed.

Activity 3: Identify default

The default case runs if none of the other cases match the value.

Match case or ELSE IF?

ELSE IF can handle many different conditions, including ranges. Switch/case is cleaner when one value is compared with fixed choices.

Activity 4: Rewrite as switch/case

switch choice:
    case "A":
        print("Add")
    case "D":
        print("Delete")
    default:
        print("Invalid")
endswitch

Activity 5: Choose the structure

ELSE IF is more suitable because the program is checking ranges, not fixed menu values.

Common mistakes

  • Forgetting to include a default case.
  • Using switch/case for range checks where ELSE IF would be clearer.
  • Checking the wrong variable in the switch line.
  • Leaving out a case for a valid menu option.
