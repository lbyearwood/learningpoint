Nested IF statements

Learn how one IF statement can be placed inside another IF statement.

Learning checklist

  • I can define a nested IF statement.
  • I can identify the outer IF and inner IF.
  • I can trace nested IF code.
  • I can explain why the inner IF may not be reached.
  • I can write a simple nested IF statement.

What nesting means

A nested IF statement is an IF statement inside another IF statement. The inner IF is only checked if the outer IF branch is reached.

Activity 1: Define nested IF

A nested IF statement is an IF statement inside another IF statement.

Login example

Nested IF statements are useful when a second check should only happen after a first check has passed.

Worked example

username = "max"
password = "apple"

if username == "max" then
    if password == "apple" then
        print("Access granted")
    endif
endif

The output is Access granted.

Activity 2: Outer and inner IF

The outer IF checks username == "max". The inner IF checks password == "apple".

Activity 3: Why is the inner IF not reached?

username = "sam"
password = "apple"

if username == "max" then
    if password == "apple" then
        print("Access granted")
    endif
endif

The outer condition is false because the username is not "max". The code inside the outer IF is skipped, so the inner IF is not checked.

Indentation and readability

Indentation shows which IF statement each line belongs to. Poor indentation makes nested decisions hard to trace.

Activity 4: Fix indentation

if has_key == true then
if door_locked == true then
print("Open door")
endif
endif

if has_key == true then
    if door_locked == true then
        print("Open door")
    endif
endif

Activity 5: Write nested IF

if age >= 18 then
    if member == true then
        print("Eligible")
    endif
endif

Common mistakes

  • Poor indentation, making the inner IF unclear.
  • Making nesting too deep when ELSE IF or Boolean operators would be clearer.
  • Tracing the inner condition before checking whether the outer condition is true.
  • Forgetting one of the endif lines.

Exam-style questions

Question 1

Define

2 marks

A nested IF is an IF statement placed inside another IF statement.

Question 2

Identify

2 marks

The username check is the outer IF. The password check is the inner IF.

Question 3

Predict

2 marks
has_key = false
door_locked = true
if has_key == true then
    if door_locked == true then
        print("Open door")
    endif
endif

Nothing is printed because the outer condition is false.

Question 4

Explain

3 marks

The outer condition may be false. If so, the code inside the outer IF is skipped, including the inner IF.

Question 5

Write

4 marks

if username == "admin" then
    if password == "safe" then
        print("Access granted")
    endif
endif

Final review checklist

  • I can identify nested IF code.
  • I can trace the outer condition before the inner condition.
  • I can write a clear nested IF statement.
